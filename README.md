# G05 FYP Portfolio

This portfolio documents the final year project "Semantic-Aware Deep-Vision Fusion: Task-Oriented Feature Extraction for Industrial Surface Anomaly Detection" for Group 05.

## Quick start
- Open `index.html` in a browser to view the portfolio.
- Weekly updates are in the `weekly/` folder.
- Folder structure diagram is at `figures/portfolio-structure.svg`.

## Folder overview
- `Documentation/` Project proposal, reports, datasheets, and application notes.
- `Software/` Simulation and code artifacts by tool (Matlab, PSCAD, AWRMO, C++).
- `Hardware/` Schematics, layouts, Gerber files, CAD drawings.
- `Portfolios/` Links or exports to external portfolio files.
- `Shared items/` Any shared items requested by the panel.

## Exporting to PDF
Open any page in a browser, then Print -> Save as PDF.

## Update checklist (weekly)
- Add goals, work done, results, and risks
- Attach evidence (image or link)
- Log files added
