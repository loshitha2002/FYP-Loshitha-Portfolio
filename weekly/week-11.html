Week 11: Quantization-Aware Training & INT8 Model Deployment

Date range: [2026-10-19 to 2026-10-25]

This week focused on implementing Quantization-Aware Training (QAT) using PyTorch's qnnpack engine to optimize our dual-branch PCB defect detection model for lightweight edge deployment on the Raspberry Pi 5 CPU.

Key Accomplishments

⚡ Quantization-Aware Training (QAT)

Integrated QuantStub and DeQuantStub into our model architecture, target-compiled with the ARM-optimized qnnpack backend. Reduced overall footprint by ~75% without accuracy degradation.

🧠 Architecture Verification

Validated feature map aggregation across 5 total feature streams: 4 multi-scale FPN feature maps ($p_2, p_3, p_4, p_5$) fused with 17 handcrafted shallow edge features (Sobel, Laplacian, Sharpen, Local Variance).

🔍 Multi-Scale & Suppression Engine

Deployed a 3-pass sliding window engine ($192\times192$, $256\times256$, $320\times320$) with automated drill-hole suppression (circularity filter $C > 0.68$ + point-in-polygon verification) to eliminate false alarms.

Technical Highlights & Methodology

  • Dual-Branch Feature Fusion: Integrates a deep VGG16-BN backbone with 4 FPN pyramid levels concatenated alongside 32 shallow edge feature channels into a 160-channel prediction head.
  • Optimization Loss Function: Combines Binary Cross-Entropy (BCE) with Dice Loss to effectively handle severe class imbalance ($<1\%$ foreground defect pixels):
    Loss = BCE(y, y_pred) + [1 - (2 * Intersection + ε) / (Sum(y) + Sum(y_pred) + ε)]
  • Target Platform: Converted final INT8 model into TorchScript format (deeppcb_vgg16_fpn_int8.pt) for execution on Raspberry Pi 5 (4-thread ARM multi-processing).
